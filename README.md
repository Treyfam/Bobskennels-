# Big Ol Bitchs Kennels

Next.js upload package for the updated kennel landing page.

## Upload

Upload this whole folder to GitHub, or replace these paths in an existing Next app:

- `app/page.tsx`
- `app/layout.tsx`
- `app/globals.css`
- `public/IMG_0315.jpeg`
- `public/IMG_0316.jpeg`
- `public/IMG_0317.jpeg`
- `public/IMG_0318.jpeg`
- `public/IMG_0319.jpeg`
- `public/IMG_0321.jpeg`

The pup photos and pedigree are served from `public`, so keep the filenames unchanged.
